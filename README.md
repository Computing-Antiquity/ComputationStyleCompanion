# Companion GitHub for the paper "Stylometric Approaches to Source Criticism: The Parables in the Synoptic Gospels as a Case Study"

The file features.txt contains all the features used to perform the stylistic analysis.

The experiments are available in the Jupyter Notebooks for the clustering and the statistical testing respectively in the files notebooks/clustering.ipynb and notebooks/statistical_testing.ipynb.

The datasets are available in the folder dataset.
